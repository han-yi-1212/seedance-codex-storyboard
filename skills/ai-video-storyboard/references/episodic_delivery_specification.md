# 🎬 单集分镜交付规范与工程标准（Episodic Delivery Specification）

本文档定义 `seedance-codex-storyboard` 单集交付物（Episodic Delivery Pack）的标准化规格，确保每一集分镜产出物均能直接投入下游切片、渲染与剪辑流水线。

---

## 一、单集物理规格基准

| 指标维度 | 工业级硬性标准 | 备注与判定说明 |
| :--- | :--- | :--- |
| **单集总时长** | **01:30.0（90.0 秒整）** | 允许 ±2 秒浮动（88.0s ~ 92.0s 闭环）。时间轴毫秒级严密连续无空隙。 |
| **单镜头时长红线** | **≤ 2.0 秒（黄金区间 0.8s ~ 1.8s）** | 严禁任何镜头超过 2.0 秒。长台词必须拆分或通过 J/L-Cut 跨镜延续。 |
| **单集镜头总数** | **55 ~ 70 个高频分镜** | 拒绝站桩拖沓，确保全程高速推进。 |
| **大镜头组划分** | **6 ~ 9 个戏剧单元** | 每组包含明确的戏剧事件，并置顶轴线与通用要求。 |
| **对白与语言策略** | **地道纯英文对白 + 中文视听指令** | 英文对白语速控制在每秒 ≤ 3.5 单词，确保口型毫秒级契合。 |
| **音频母带规范** | **三层纯净分轨（无脏 BGM）** | 仅保留清晰对白音轨 + 物理拟音（Foley）+ 空间底噪（Ambience）。 |

---

## 二、标准分镜文档结构组织（Markdown 输出格式）

单集交付文档必须严格遵循以下三层模块组织，保存为 `output/E{XX}_{集名}.md`：

### 1. 头部：《全片/本集统一视觉规范》
```markdown
# 🎬 AI短剧分镜｜《[剧名]》E[XX]：[集名]（v6.0工业工程落地版）

**总时长：01:30.0（90.0秒整）｜XX个镜头｜单镜头最长1.8秒｜严格遵循工业工程生成标准**

---

## 全片统一视觉规范

**角色统一：**
- [角色名]：[年龄、身材、五官微特征、发型、标志性服装面料、随身配饰道具]
...

**摄影风格：**
9:16竖屏，好莱坞高概念质感，浅景深锐利焦点，机械阻尼重量感。

**光影逻辑：**
[明确场景冷暖色温与主光方位]

**音频母带规范：**
纯净三层音轨（人声对白 + 物理拟音 + 空间底噪），无背景音乐（BGM），镜头之间硬切。
```

---

### 2. 主体：连续分镜主体（大镜头组化管理）
以“大镜头组（Master Shot Group）”为单元，组内包含连续编号的十维单镜头：
```markdown
## 🎬 连续分镜主体（大镜头组化管理）

### 大镜头1：[戏剧单元小标题]
**本组时长：** XX秒 ｜ 每个分镜不超过2.0秒。

**通用要求：** 9:16竖屏，正常速度、真实表演。角色形象、服装和场景布局遵照视觉规范。角色A左、角色B右，保持同一轴线与视线方向。道具持有状态锚定。英文对白跨镜连续，听者闭口听不跟随口型。无BGM，镜头之间硬切。

---

[00:00.0-00:01.3] 镜头1：
场景：...
景别：...
机位：...
拍摄角度：...
运镜：...
画面动作表演：...
【对白/口型】：...
【语气/发声】：...
光影：...
音效：...
```

---

### 3. 尾部：《生成质检红线清单》
```markdown
---

## 生成质检红线清单（Redline Checklist）

- [x] **轴线与视线检查**：大镜头组声明左右站位，所有正反打保持视线对撞与同侧轴线。
- [x] **口型防翻车检查**：画外音镜头均显式标注“听者闭口听，不跟随口型”。
- [x] **语气微指令检查**：每个对白镜头均具备独立的【语气/发声】字段。
- [x] **去文学化修辞检查**：动作全部转化为微物理形变与生理信号。
- [x] **道具守恒检查**：随身关键道具在连续镜头中均有手位交代。
- [x] **纯净音频检查**：彻底剥离 BGM，仅保留人声、拟音与底噪。
- [x] **时长与切分检查**：单镜头严格 ≤ 2.0 秒，时间戳连续闭环。
```

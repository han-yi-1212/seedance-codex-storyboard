# Seedance & Codex 视听工程落地执行手册

本文档为 `seedance-codex-storyboard` (v6.0) 的深度配套工程手册，专为 **Seedance 视听创成平台** 与 **Codex 自动化管线** 深度适配，指导如何生成面向 AI 视频扩散/DiT 大模型与神经音频管线的零返工分镜工程提示词。

---

## 一、声画解耦与防对口型翻车（Lipsync Anti-Bleeding）

### 1. 核心问题根源
多模态音视频大模型（Audio-to-Video / Lip-sync 工具）在处理对白画面时，默认逻辑是：**“如果画面中有人物且当前音轨有声音，模型会自动将人物嘴部匹配当前音频的振幅与音素”**。
这会导致极严重的翻车：
- 画面明明是“听者”的特写反应镜头，但听者的嘴唇却跟着画外音张合，变成诡异的“腹语术”；
- 换镜时出现喘气断裂或对不上口型的假人感。

### 2. 标准工程约束模式

#### 模式 A：画内说话（Speaker In-Frame）
```markdown
【对白/口型】：雷诺：“Voss, first day,”；画内同步英文口型，向下一镜连续。
【语气/发声】：中等音量，起音平稳，Voss清楚点名，first day自然连读；句中短停轻，不把这一段读成独立结束的一句。
```

#### 模式 B：画外续说（Speaker Off-Screen, Listener In-Frame / J-Cut & L-Cut）
```markdown
【对白/口型】：雷诺画外续说：“just get the lay of the land.”；埃拉闭口听，不跟随口型。
【语气/发声】：延续同一条雷诺音轨，语速轻快自然，get the lay of the land连贯说完，句尾轻落，不在切镜处重新吸气起句。
```

#### 模式 C：闭口反应或动作（No Dialogue）
```markdown
【对白/口型】：无；嘴唇保持自然闭合。
【语气/发声】：无对白。
```

## 二、TTS 神经语音提示词控制微词典

在【语气/发声】字段中，必须采用能够精确指导语音模型或配音采样的工程词汇：

| 控制维度 | 标准工程描述示例 | 避免的模糊文学词汇 |
| :--- | :--- | :--- |
| **起音与连读** | `起音平稳，first day自然连读`、`不吸气起句` | *温柔地开口*、*充满磁性* |
| **重音位置** | `east wing清楚落重音`、`ask与nothing咬字收实` | *强调地说*、*冷酷地警告* |
| **停顿控制** | `Remember后短停约0.1秒`、`句中短停轻，不读成独立句` | *犹豫了一下*、*沉默片刻* |
| **尾音走势** | `尾音向下压，后半句继续连到下一镜`、`句尾自然落下不拖长` | *意味深长*、*叹息着结束* |
| **呼吸与气声** | `保留细小鼻吸，不额外补气声或笑声` | *深深地吸了一口冷气* |

## 三、180° 轴线与视线几何锁死（Action Line & Eye-line Control）

### 1. 为什么 AI 视频容易出现“视线飘忽”和“左右颠倒”？
AI 视频工具在单镜头生成时没有全局记忆。如果提示词只写 `雷诺看着埃拉`，AI 随机生成雷诺看左或看右；切到埃拉时又随机看左或看右，导致剪辑组接时两人视线同向（都在看右边），瞬间破坏空间逻辑。

### 2. 轴线工程模板
在【大镜头组】与【机位】中双重锚定：
- **大镜头组声明：** `雷诺左、埃拉右，所有反打保持同一轴线与视线方向。`
- **雷诺镜头：** `机位：埃拉视线同侧，雷诺看向画面右。拍摄角度：前侧45度平视。`
- **埃拉镜头：** `机位：雷诺肩后，同一轴线侧，埃拉看向画面左。拍摄角度：前侧30度平视。`
- **插切手部镜头：** `机位：两人侧面，保持原轴线。`

通过几何方位的显式固化，AI 生成时能稳定维持正确的左右对峙关系。

## 四、去文学化与微动作防畸变（De-Literarization & Anti-Morphing）

### 1. 文学修辞 vs 机器物理描述对照表

| 剧本常见文学描述 (❌ AI 无法理解) | 工业级物理化描述 (✅ 机器直接渲染) |
| :--- | :--- |
| 他散发着上位者的冰冷压迫感 | 嘴角的弧度收平，眉间收出一道浅折，头微微压低，双眼停在埃拉脸上，下颌收紧 |
| 她倔强不屈，心头巨震 | 眼神停住，目光直视对方脸上，下巴轻收，下唇抿紧，鼻间短吸一口气，肩膀保持平稳 |
| 两人之间涌动着暧昧的空气 | 两人站立距离缩短至半臂，视线在眼眸处固定0.8秒，胸口起伏频率一致 |
| 亲切地拍了拍她的肩膀 | 右手落在近侧肩头，轻拍一下，掌心短暂接触后自然收回；肩部随接触轻微下沉再复位 |

### 2. 动作幅度与 AI 畸变风险
- **绝对规避：** 大幅度全身剧烈旋转、快速肢体交叉打结、复杂的双手多关节互握、快速穿脱衣物。
- **推荐高成功率动作：** 极小幅度的点头/摇头、视线转动引动头部微转（先动眼后动头）、手指轻触/微抬、下巴微抬/微收、胸膛微弱呼吸起伏。

## 五、纯净三轨音频工程规范（Stem Audio）

为方便后期专业混音，分镜脚本中的音效必须做纯净分离：
1. **Dialogue（人声）**：清楚人声、起音落音明确、无混响污染。
2. **Foley（拟音）**：真实的微物理声音（衣料摩擦声、鞋跟轻触地面声、手指接触声、细小鼻吸呼吸声）。
3. **Ambience（空间底噪）**：轻微的走廊低频环境底噪、中央空调风声、远处极低频办公底噪。
4. **BGM / 冲击音效**：**禁止在分镜生成阶段加入！** 任何 “重音效轰鸣”、“大提琴哀鸣”、“悬疑刺耳声” 都会污染生成素材，必须完全留给后期 NLE 剪辑软件中统一挂载。
